# UI review: Phase 0 screens (2026-11-11)

Reviewer: `ui-ux-designer` · Against: `screens/sign-in.md`, `screens/today-placeholder.md`, design-system v0.4 (incl. §11)

**Method.** `design-taste-frontend` is not installed (§0, option A); §11 was used. No shell tool was available, so **no screenshots were taken**. This is a static review. Re-run the 360/1280 light/dark capture before merge. `tokens.css` values are correct and unchanged. Dark pairs: muted/bg 7.3:1, accent-contrast/accent 7.5:1, border-strong/surface 3.06:1.

## Verdict: **APPROVE WITH CHANGES**

## BLOCKING

1. **Typed input is lost on errors** (S2, S7, S10, S11; §11.5). React 19 resets uncontrolled fields after a `<form action>`. `src/features/auth/ui/sign-in-form.tsx:98-108`, `:128-139`. **Fix:** make the inputs controlled (`useState` + `value`/`onChange`). On S7, select the code.
2. **Offline primary still submits** (S12). `:112`, `:141` only `disabled={busy}`. **Fix:** `onSubmit={(e) => { if (blocked) e.preventDefault(); }}` on the forms at `:92` and `:123`. Link the reason (`:86`) to the button via `aria-describedby`.
3. **Focus falls to `<body>` on step change and errors** (S2, S5, S7, S13; WCAG 2.4.3). **Fix:** a ref plus an effect on `state`. On the code step, focus the OTP input. On `invalid_email`/`bad_code`, focus the field. On Today, focus the `<h1 tabIndex={-1}>` (`src/app/(app)/today/page.tsx:20`).

## NON-BLOCKING

4. **No email echo** (S5), `:121`. **Fix:** show `state.email` with "Use a different email" (move `:157-162`) above the OTP field.
5. **S7/S8 fold (ADR-0006): resend isn't next to the error.** The error is at `:140`; resend is an outline button after the primary (`:145-156`). **Fix:** make it `btn-text` directly under the error. During cooldown use `aria-disabled` only (it stays focusable) and put the countdown in adjacent text. Copy requests to product: `badCode` should mention expiry; add a non-breaking space in "{seconds} s".
6. **§8 form-error pattern missing.** **Fix:** order label → hint → input → error (`:95-111`). Add a 2 px `--text` border on `[aria-invalid]` in `.field-input` (`globals.css:92`) and a 16 px info glyph. Use `aria-describedby="hint error"`.
7. **Primary button not in the display font** (§6). **Fix:** `globals.css:72` → `font-family: var(--font-display)`.
8. **Disabled opacity 0.6 drops the label to about 2.9:1 (light) and 3.5:1 (dark)**, `globals.css:67-71`. Inactive controls are exempt, but offline buttons carry meaning. **Fix:** keep full opacity and rely on the visible reason.
9. **Switch placement is inconsistent and there's no header.** Sign-in puts it above the h1 (`src/app/sign-in/page.tsx:39`); Today puts it beside the h1 (`today/page.tsx:19-22`). **Fix:** a shared `AppHeader` (`<header>`, app name left, switch right) outside `<main>`.
10. **Switch shows both languages, with the current one outlined** (`src/components/language-switch.tsx:11-24`), contrary to spec §8. **Fix:** render only the other language as `btn-text` with `lang`. Not verified in a browser: whether switching keeps the step and typed values.
11. **Today emphasis is inverted** (§11.4), `today/page.tsx:23-24`. **Fix:** h1 → signed-in line (muted, check glyph) → placeholder (`--text`). Sign-out should be 48 px and full width at 360: `sign-out-button.tsx:15` add `min-h-[var(--control-height)] w-full sm:w-auto`.
12. **Hard-coded widths.** `sign-in/page.tsx:38` uses `max-w-[480px]` (spec 400); `today/page.tsx:17` and `src/app/page.tsx:10` use `[640px]`. **Fix:** `max-w-[var(--form-max)]` / `[var(--content-max)]`. The sign-in h1 `text-2xl` should be `text-xl`.
13. **`/` is a splash/hero** (§11.9, §11.12; unspecced), `src/app/page.tsx:8-23`. **Fix:** redirect `/` → `/today` (the proxy handles signed-out users).
14. **CLS risk.** Turnstile has no reserved height (`:65-73`, `:147`). **Fix:** a `min-h-[65px]` wrapper when a site key is set.
15. **`/offline` says "You're offline" twice** (`content/messages/en.json:54-55`; copy request to product). It's centered (`src/app/offline/page.tsx:9`); top-align it.
16. **OTP paste.** `maxLength={6}` (`:134`) truncates "123 456". **Fix:** strip non-digits in `onChange`.

**Passes:** one filled primary per view (none on Today) ✓ · `.btn` ≥ 44 px, inputs 48 px ✓ · focus ring visible in both themes ✓ · no banned words or guilt language ✓.
